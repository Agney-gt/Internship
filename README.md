# GC Internship Training

> Forked from [Agney-gt/Internship](https://github.com/Agney-gt/Internship)

An internship training repository focused on Python development and web scraping using Selenium.

## Tech Stack
- Python
- Jupyter Notebook
- Selenium

## Onboarding Task
1. Fork this repository
2. Create a folder with your name
3. Add a Python file that uses Selenium to scrape Google search results
4. Submit a pull request

## Resources
- Python coding standards video (linked in repo)
- [MIT Missing Semester](https://missing.csail.mit.edu/)
- `.flake8` config for code linting

## Getting Started
```bash
git clone https://github.com/mrsandeep27/GC-Internship.git
cd GC-Internship
pip install -r requirements.txt
```
